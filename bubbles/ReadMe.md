# Bubbles
## By R.Rumsey, Jan 2025

Python Modules for analyzing bubbles in Hyperspectral images of ice cores

- Output will display a binary mask of the ice core image with bubbles in white. Red ellipses should surround each bubble with proper orientation and elongation.
- A csv file can also be output with each bubble's area, centroid, orientation, elongation, eccentricity, and bounding box.

# To Use
1. Navigate to the Notebook folder
2. Open spectralBubbles.ipynb

This notebook currently points to a csv datafile on all ice cores scanned during the July 2024 CPL. To access a particular scan: edit the DataID string.
